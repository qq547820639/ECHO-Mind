# 部署手册

## 本地

```bash
cp backend/.env.example backend/.env
cd backend
pip install -e '.[dev]'
python scripts/seed_demo.py
python scripts/create_demo_tokens.py
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

## Docker

```bash
docker compose up --build
```

## 生产建议

- 单租户 VPC；数据库、对象存储和密钥隔离
- 反向代理终止 TLS 1.3，WAF、限流、IP/设备异常检测
- 机构 SSO/OIDC 与 MFA
- PostgreSQL 高可用、加密备份、按季度恢复演练
- 通知链使用至少两条通道，并监控送达和升级
- 服务端日志发送到独立不可篡改审计域

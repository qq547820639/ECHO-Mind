## A. 修改摘要

### P0 — 数据可靠性
1. **sources_present 覆盖度契约修复**：`gap_finder` 改为以「当日全部窗口 `sources_present` 并集」为窗口 modality coverage 权威；历史空列表 fallback 到 `f.source`；`mic_opt` 可选（未授权不产生 gap）；`health` 不在 EXPECTED_SOURCES 不擅自 mandatory；gap_id 幂等不变。`audit_day` summary、`profile` traits/events 同步补充 sources_present 并集，消除"只读 singular source"的同类缺陷。
2. **消除 sensing 窗口静默数据丢失**：SensingEventHub 新增 `HubSnapshot` + `snapshotAll()`（非破坏）+ `clearConsumed(snapshot)`（引用相等，只清已消费项）；flush 流程改为 snapshot → extract → Room `withTransaction` 批量落库 + outbox → **成功后才 clear** → enqueue sync；`onWindowReady` 返回明确 Success/Failure；失败窗口不进 flushed 集、bounded retry ≤3；AppPreferences 新增 `lastSuccessfulCollection` / `lastPersistenceFailure` / `consecutivePersistenceFailures`（"数据与感知"页可区分六种采集状态）；consent revoke 立即清原始内存且不补发；原始数据不写磁盘。
3. **彻底删除被动 mood inference 残留**：`tool_forge` 删除 `mood_check` 模板（mood_score/trend improving/declining 全部消失）；`skill_induct` 删除 `mood_check → reflection_prompt` 映射；app/ 源码 grep `mood_check` 0 命中。结构性测试保证 Gap Finder 永不生成 mood/depression/suicide/diagnosis 型 gap、Tool Forge 无被动情绪模板、Skill induction 无情绪路径、`/features/ingest` 永不创建 RiskSignal/Escalation。

### P1 — 产品化与体验
4. **旧主动趋势 API 退休**：全仓验证 Android/scripts/console 均无 `/v1/trends/summary` 真实调用 → **移除契约**（现 404）；`build_trend` 降级为 case-review 内部数据质量用途（`# legacy: v0.8 后移除`）；OpenAPI/tests/docs 同步。Checkin 表保留历史只读兼容。新趋势统一由 DerivedFeature → DailyNarrative → batch profile 承载。
5. **Onboarding 产品化**：真实用户不再填写 u_demo/内部 user_id/access token/机构配置令牌；单「激活码」→ 新增预认证 `POST /v1/onboarding/verify-code`（复用 User.external_ref + create_access_token，响应经 response_model 保证不含 tenant_id/role/external_ref）；本地七态状态机（NOT_STARTED/ACTIVATING/ACTIVATION_FAILED/BOUND/CONSENT_PENDING/READY_OFFLINE/READY），`onboardingCompleted` 仅 READY/READY_OFFLINE 为 true，与服务端激活一致；8 步渐进披露；保留 18+/紧急入口/分项 consent/麦克风独立 consent/可撤回；网络恢复后同步 Worker 幂等收敛不重复建 user/consent。
6. **Skill 原生执行 UX 深化**：修复缺陷 7——`parseSkillsArray` 此前丢弃 action_type/estimated_duration/completion_schema/safety_constraints/revision，现全部保留到 `SkillDisplay`；action_type 白名单分发器（guided_steps/breathing/checklist/journaling/reflection_prompt）5 个原生 Compose Renderer（呼吸引导含节奏/暂停/停止/TalkBack/暗色，无医疗宣称；journaling 仅按 completion_schema 要求结构化输入，不回归旧日记）；未知 action_type **fail closed**（不渲染开始、不产生 completion）。
7. **ActiveSkillSession 持久化**：Room v5 新表 `active_skill_sessions`（12 字段）；duration 语义 = `accumulatedActiveMs + current running segment`，**暂停不计时**（fake clock 单测：start→pause→wait→resume→complete 断言 pause 不入时长）；跨 recomposition/tab/activity recreation/process death/app restart 恢复（死亡恢复为 PAUSED 不虚增时长）；completion 保持 event_id 幂等。
8. **Narrative/Profile 深化**：narrative events 增加 `sources_present`、profile traits 增加 `sources_present_union`；全部为描述性行为数据，无情绪推断；`DailyNarrative.gaps` 保持 `[]` + legacy 预留注释（真值在 SandboxRun.gaps_found）；数据不足走 `insufficient_data` 语义。
9. **趋势七态 UX 细化**：NO_DATA 不再统一"暂无数据"，按原因区分（新用户无窗口/权限未授权/用户关闭/系统限制后台/部分 source 缺失/本地持久化失败/等待上传/服务器不可用）；展示最近成功采集/保存/同步（非工程术语）；权限问题提供 `Settings.ACTION_APPLICATION_DETAILS_SETTINGS` deep link；支持页新增持久化失败观测行。

### P2 — 工程与治理
10. **Scheduler/Collector 健壮性**：`flushedWindowStarts` 有界（保留最近 48 窗口，bounded dedupe range）；SensorCollector timestamp 评估结论：保留现状（5 分钟边界 flush 使缓冲天然属刚结束窗口，无实际收益），代码注释记录未来引入路径。
11. **Legacy 隔离**：A 类（410 存根/认证链）不动；B 类（Checkin/QuestionnaireResult/PracticeCompletion model/schema、build_trend）加 `# legacy: v0.8 removal target` 注释；C 类死代码删除——Android 删除 QuestionnaireScreen.kt、QuestionnaireScorer.kt、saveCheckin/saveJournal/saveQuestionnaire/recordPractice/enqueueEscalation、CheckinInput/JournalInput/QuestionnaireScore/QuestionnaireDefinition/PracticeDefinition、NarrativeDisplay.moodHint 等字段。
12. **仓库治理**：docs/15b 方案给出 source-of-truth 七层分类 + docs/README.md 索引草案 + ADR-001（sources_present 唯一真相）/ ADR-002（被动 mood 永久禁止）；legacy 移动清单（只移不删，提示 FILE_HASHES 需重算）。
13. **CI 深化**：backend-ci 重构 7 job（lint-typecheck=ruff+mypy / test-sqlite / test-postgres=PG service+coverage≥70 / alembic-postgres round-trip / static-checks / openapi-drift / contract-drift）；android-ci 增 connected-test 矩阵（API 34/36 骨架）；security-ci 增 CodeQL/dependency-review/pip-audit/osv-scanner/trivy；dependabot.yml 覆盖 github-actions/pip/gradle；actions 可变 tag 标注 `TODO(T03): pin to commit SHA`。
14. **契约漂移防线**：新增 `docs/contract-manifest.json`（required 10 端点 / removed 1 / deprecated_410 4 类 / 字段契约）+ `scripts/contract_drift_check.py` + `scripts/fault_injection_check.py`（故障注入矩阵 16 项 + 4 边界锚点，本地实测 **18/18 PASS**）。

## D. API 契约变化

- **删除**：`GET /v1/trends/summary`（现 404）
- **新增**：`POST /v1/onboarding/verify-code`（预认证；`{code: 8..80}` → `{user_id, access_token, consent_versions, l0_decision, restricted}`；无效码 404 / restricted 403；写 audit `onboarding.verify`）
- **字段新增**：narratives events `sources_present`；profile traits `sources_present_union`；audit_day summary `sources_present`（内部）
- **跨端契约**：sources_present 枚举 7 值、action_type 白名单 5 项、SkillOut 执行契约 4 字段、SkillCompletion.status 枚举、OnboardingVerifyOut 禁止字段（tenant_id/role/external_ref）——全部写入 contract-manifest.json 并由 contract-drift job 防漂移

## E. 数据库变化

- Migration `20260810_0002_v06_final`：upgrade 建 `ix_users_external_ref`（非唯一）；downgrade 删索引；down_revision=20260810_0001；inspector 幂等
- SQLite round-trip 实测通过：upgrade head → downgrade base → upgrade head（head=20260810_0002）
- Android Room v4→v5：纯增量建 `active_skill_sessions`（CREATE TABLE IF NOT EXISTS 幂等）
- 无删列/改列；mood 相关列保持 deprecated 兼容，新写入恒空

## F. Android UX 变化

- **Onboarding**：真实用户只见一个激活码输入框；内部标识字段从 release/pilot UX 消失；多步渐进披露（欢迎→激活→边界→consent→L0→紧急联系人→感知说明→完成）
- **Skill**：不同 action_type 有专属原生交互（引导步骤/呼吸节奏/清单进度/结构化反思）；未知类型显示"此能力暂不可用"；执行中断后重开应用可"继续/结束"恢复
- **趋势页**：不再统一"暂无数据"——按真实原因显示差异化文案；权限问题一键跳系统设置页
- **支持页**：新增采集健康观测（最近持久化失败/连续失败）
- **呼吸/反思等 Renderer**：无医疗功效宣称、无情绪评分输出

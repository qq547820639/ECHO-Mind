# 隐私、安全与威胁模型

## 主要威胁

| 威胁 | 控制 |
|---|---|
| 手机丢失 | Keystore、字段加密、无明文备份、会话超时 |
| 跨租户越权 | JWT tenant_id、每次查询强制租户过滤、403 测试 |
| 日志泄漏 | 结构化白名单日志，禁止敏感正文 |
| 风险事件丢失 | 本地高优先级 outbox、幂等重试、未送达状态 |
| 假人工确认 | ACK 是服务端状态，不由客户端自行推断 |
| 动态代码进入安全链 | 生产禁用动态代码/工具生成，签名内容包 |
| 内部人员滥用 | 最小权限、MFA、导出告警、审计哈希链 |
| 模型提示注入 | 安全关键逻辑不交给 LLM，工具白名单与 JSON Schema |
| 麦克风授权撤回后仍采集 | `OnPermissionsChangeListener` 监听撤回 + 写 `voice_features` revoked consent + 停止 MicCollector；后端对 `mic_opt` 特征校验 consent 有效（412） |
| 群体画像再识别 | 聚合桶计数 < 5 合并到 "other" 桶；不返回单个用户 ID/特征；admin/professional/auditor 角色限制 |
| 沙箱资源耗尽 | 单次超时 120s 转 failed + 租户并发上限 4（429）+ 每小时速率限制 10（429） |
| 灰度回滚失效 | feature flag 前置依赖（关闭返回 410）+ 端侧拉取 flag 联动 + batch-retire 批量回滚 |

## 同意类型清单

| consent_type | 范围 | 撤回效果 |
|---|---|---|
| `passive_sensing` | 端侧被动采集 + ingest | 撤回后 `POST /v1/features/ingest` 返回 412 |
| `voice_features` | 麦克风派生特征（`source=mic_opt`） | 撤回后 `mic_opt` 特征返回 412；端侧停止 MicCollector |

## 生产前必须替换

- 服务端备注明文演示字段 → KMS/字段加密
- 本地 JWT 密钥 → HSM/KMS 托管和轮换
- 简单工作台 → 机构 SSO、MFA、会话管理、CSRF/CSP
- SQLite → PostgreSQL 单租户/独立 VPC

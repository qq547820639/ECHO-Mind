# 仓库文档治理方案（v0.6 收口）

> 作者：产品经理 许清楚（Xu）｜版本：v0.6｜状态：治理方案（整理现状，不新增功能）
> 适用对象：`docs/`、根目录 RELEASE_NOTES / README / 交付物、`content-packs/`、`pilot-pack/`、`releases/`
> 铁律：本方案只做**移动、索引、标注**，不做删除；仍用于审计/历史交付的旧文档一律保留。所有内容继续遵守**非诊断、非医疗**边界。

---

## 0. 治理原则

1. **Source of truth 分层**：每一份文件都能回答"它是什么层、是否现行、被谁引用"。
2. **只移动不删除**：历史/过时文件移入 `docs/legacy/` 或 `docs/archive/` 子目录，保留审计与追溯价值。
3. **文档必须可被索引**：`docs/README.md` 作为唯一入口索引，标注每份文件的状态与替代关系。
4. **现状以代码为准**：任何文档与代码冲突时，以代码与 `openapi.json` 为准；过时文档必须标注"superseded by"。

## 3. ADR 草案

### 3.1 ADR-001：`sources_present` 为窗口覆盖度唯一真相

```markdown
# ADR-001：sources_present 是窗口覆盖度的唯一真相

状态：Accepted（v0.6）
日期：2026-08-10

## 背景
端侧派生特征需要向服务端表达"这个 5 分钟窗口里实际采到了哪些信号"，
避免把"没数据/权限关闭/未授权"误报为"行为正常"。

## 决策
- `DerivedFeatureIn.sources_present`（可选 `list[Literal[...]]`，`extra="forbid"`）
  是窗口覆盖度的**唯一**机器可读真相；后端 gap_finder / 趋势页不再从
  summary 文本猜测覆盖度。
- 覆盖度字段不允许包含原始数据或可重识别信息，只表达"哪些信号源存在"。

## 影响
- 端侧 FeatureExtractor 必须正确填充；缺失/为空视为"无覆盖"，不得推断"正常"。
- 趋势页"数据覆盖度"指标只以该字段为准（配合 01b 契约点 8 七态）。

## 关联
- docs/01b_PRD增量_v0.6.md（sources_present 契约）；backend schemas.py；Android FeatureExtractor.kt
```

### 3.2 ADR-002：被动 mood inference 永久禁止（含删除记录）

```markdown
# ADR-002：被动行为数据推断情绪/自杀意图/精神疾病 永久禁止

状态：Accepted（v0.6）｜类别：安全/伦理红线
日期：2026-08-10

## 背景
v0.2 时代存在"行为遥测 → 情绪/危机"的错误语义映射，违背非诊断边界。

## 决策（永久禁止，不可因后续迭代回退）
- 禁止用途：被动行为数据（加速度/陀螺仪/屏幕/通知/App 活跃/麦克风派生特征）
  不得用于推断：情绪、自杀意图、自伤意图、精神疾病、抑郁/焦虑诊断；
  也不得据此自动触发危机事件或冻结生成。
- 允许用途（仅非诊断）：数据覆盖度、活动节律、屏幕互动变化、
  非诊断行为趋势、中性关怀/人工支持入口的展示。
- 危机信号唯一来源（白名单）：用户主动求助 / L0 当前危险 / 主动文本 RED /
  专业人员人工事件 / 临床负责人签署量表中需人工复核的明确项。

## 本次删除记录（v0.6）
| 项 | 位置 | 处理 |
|---|---|---|
| 端侧 SafetyEngine.evaluatePassive | android/.../sensing/SafetyEngine.kt | 删除/降级恒 NONE，不再由 saveDerivedFeature 调用 |
| 后端 evaluate_passive 调用 | backend/app/api/routes.py ingest 路径 | 移除被动 RED 触发 |
| 情绪标签映射 | backend/app/services/profile.py `_mood_hint_from_summary` | 删除；mood_hint 字段置空兼容 |
| 端侧情绪评分折线 | android/.../ui/OtherScreens.kt TrendScreen | 删除伪精确折线，改行为派生指标 |
| 文案 | android strings.xml / Kotlin | 禁止"情绪低落/情绪平稳/更积极/最近情绪"等 |

## 影响
- 任何新迭代若引入"行为特征 → 情绪/诊断"映射，视为红线违规，CI 宣称扫描应拦截。
- 趋势页必须保留固定免责文案（01b 契约点 2）。

## 关联
- docs/01b_PRD增量_v0.6.md 契约点 1/2；docs/04 危机 SOP（被动 RED 移除后需同步刷新）
```

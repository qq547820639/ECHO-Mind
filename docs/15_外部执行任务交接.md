# 外部执行任务交接

## Android 团队

1. 在联网环境执行 `./gradlew test assembleDebug lint`。
2. 修复全部编译、lint 和 Room schema 问题。
3. 运行 `pilot-pack/10_设备测试矩阵.csv`。
4. 配置 HTTPS、证书固定轮换和正式签名。
5. 输出 APK/AAB、测试报告、依赖锁和构建 provenance。

## 平台/安全团队

1. 部署单租户 PostgreSQL、KMS/HSM、TLS、WAF、监控和备份。
2. 运行 Alembic staging 回放和灾难恢复。
3. 接机构 IAM/SSO/MFA，禁止共享值班账号。
4. 完成外部渗透和复测。
5. 保存 SBOM、镜像摘要、配置和密钥轮换证据。

## 临床/机构团队

1. 签署内容包、L0、规则、脚本和排除条件。
2. 填写责任矩阵和值班表。
3. 完成培训和危机演练。
4. 建立投诉、不良事件和随访流程。
5. 按 Go/No-Go 决策后才能招募用户。

## 法务/隐私/伦理

1. 定稿隐私政策、单独同意、PIPIA、保留期和合同角色。
2. 判断算法备案、安全评估、研究伦理和应用商店要求。
3. 核查所有 SDK/处理者和数据位置。
4. 审核应用内、客服、合同和商店宣称。

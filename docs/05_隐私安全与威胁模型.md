# 隐私、安全与威胁模型

## 主要威胁

| 威胁 | 控制 |
|---|---|
| 手机丢失 | Keystore、字段加密、无明文备份、会话超时 |
| 跨租户越权 | JWT tenant_id、每次查询强制租户过滤、403 测试 |
| 日志泄漏 | 结构化白名单日志，禁止敏感正文 |
| 风险事件丢失 | 本地高优先级 outbox、幂等重试、未送达状态 |
| 假人工确认 | ACK 是服务端状态，不由客户端自行推断 |
| 动态代码进入安全链 | 生产禁用动态代码/工具生成，签名内容包 |
| 内部人员滥用 | 最小权限、MFA、导出告警、审计哈希链 |
| 模型提示注入 | 安全关键逻辑不交给 LLM，工具白名单与 JSON Schema |

## 生产前必须替换

- 服务端备注明文演示字段 → KMS/字段加密
- 本地 JWT 密钥 → HSM/KMS 托管和轮换
- 简单工作台 → 机构 SSO、MFA、会话管理、CSRF/CSP
- SQLite → PostgreSQL 单租户/独立 VPC

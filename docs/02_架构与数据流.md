# 架构与数据流

```text
Android App
  ├─ Onboarding / Consent / L0
  ├─ Check-in / Questionnaire / Practice / Trend
  ├─ SafetyEngine（确定性）
  ├─ Room + Keystore 字段加密
  └─ 高优先级 Outbox
          │ TLS + JWT + 幂等 event_id
          ▼
FastAPI Gateway / Case Service / Escalation / Audit
          │
          ├─ PostgreSQL（生产）
          └─ Clinician Console
```

## 安全边界

- 主生成模型不在本交付包的危机判定链中。
- 手机端红色规则命中后立即冻结普通生成。
- 风险事件是追加式记录，不能被普通业务更新覆盖。
- 只有服务端 ACK 后才能显示“人工已收到”。
- 只有 professional/admin 且已 takeover 的事件可关闭。

## 数据最小化

- 日志不记录对话正文、量表答案和紧急联系人。
- App 示例采用 Keystore AES-GCM 对敏感字段和离线 outbox 加密。
- 服务端演示数据库中的备注字段尚未接 KMS；生产发布前必须替换。

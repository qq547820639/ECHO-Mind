# PRD：ECHO Mind Android Path A MVP

## 目标

为 18 岁以上机构用户提供低负担日常状态记录、结构化筛查提示、审核练习、个人趋势和确定性人工支持入口。

## 成功指标

- 首次流程中位时长 ≤5 分钟
- 每日签到中位时长 ≤45 秒
- 明确高危表达一轮内冻结普通生成并创建 L3 事件
- 拒绝可选权限不影响核心功能
- 人工工作台能展示证据、等待时间和责任人，而非单一 AI 分数

## 核心故事

1. 用户能理解 AI 身份和非诊断边界后进入应用。
2. 用户可在 45 秒内完成签到并查看个人趋势。
3. 用户可完成固定版本 PHQ-9/GAD-7，看到原始分数和中性提示。
4. 用户可选择已审核练习，随时停止。
5. 用户主动求助或出现明确危机表达时，应用停止普通生成并启动人工链路。
6. 值班人员可确认、接管、记录处置；只有人工可关闭事件。

## 不做

- 面部情绪识别、后台录音、小米手环、iOS、开放式无限陪聊、自动诊断、自动治疗方案、自动药物建议。

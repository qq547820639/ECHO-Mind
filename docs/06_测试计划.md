# 测试计划

## 自动化

- 量表长度、取值、分数和高风险题项
- 高危、隐晦、退出、普通文本
- 幂等提交
- 跨用户/跨租户越权
- 未接管前禁止关闭事件
- 审计哈希链连续性
- 离线 outbox 优先级

## 被动感知范式

- `DerivedFeatureIn` schema `extra="forbid"`：拒绝原始传感字段（audio_buffer/raw_samples/payload）
- `passive_sensing` consent 撤回后 ingest 返回 412
- 被动 RED 信号（PASSIVE_RED_TERMS）触发冻结 + escalation
- 否定语境不误触发被动 RED
- 端侧 FeatureExtractor 产出对齐契约（summary≤4000, vector≤256）

## 自进化沙箱

- Zero-Skill 冷启动不报错，生成首批候选 Tool
- 完整回路：audit_day → gap_finder → tool_forge → validator → induct
- Skill 下发前脱敏（无其他用户数据、无原始特征引用）
- Skill 治理状态机 Draft→Reviewed→Signed，admin/professional 审签
- 沙箱调度租户隔离

## E2E 隐私验收

- 被动 RED 审计哈希链跨多事件验证（head_hash + 事件序列）
- 跨租户 audit 链隔离
- DSR delete/revoke 对被动感知数据清理（DerivedFeature + RiskSignal）
- 沙箱完整回路 E2E（ingest → narrative → sandbox run → skill 下发 → 脱敏断言）
- Android 全链路数据流：FeatureExtractor → DerivedFeatureInput → ingest payload → SkillDisplay（隐私不变量）
- 隐私抓包断言：请求体仅含 summary/vector，无原始传感 payload/音频
- 已停用路由返回 410 Gone（checkins/journals/safety-check/questionnaires/practices）

## 待明确项收尾（P1-P5）

### P1 麦克风授权证据闭环
- `mic_opt` 特征无 `voice_features` consent → 412
- 有 `voice_features` consent（granted=true）→ 201
- consent 撤销（granted=false）后 → 412
- 非 `mic_opt` source（如 `motion`）不要求 consent → 201
- Android MicCollector 权限撤回监听停止采集

### P2 沙箱算力预算
- 单次 run 超 `sandbox_timeout_seconds` 转 failed（error_message 含 timeout）
- 同租户并发达 `sandbox_max_concurrent` 返回 429 `sandbox concurrency limit reached`
- 同用户每小时达 `sandbox_rate_limit_per_hour` 返回 429 `sandbox rate limit exceeded`

### P3 冷启动兜底文案分阶段
- `GET /v1/skills` 空列表返回 `cold_start_hint` 字段
- 4 档阶段与 `observation_days` 对应（0/1-3/4-7/7+）
- 非空列表时 `cold_start_hint` 为 null
- Android 4 档文案 stage → 资源 ID 映射 + 加载失败重试

### P4 机构去标识群体画像
- 聚合正确性（mood 分布/observation 统计/活跃用户/escalation/Skill 计数）
- 小桶（<5）合并到 "other" 桶
- 跨租户隔离（只返回本租户聚合）
- 角色权限（user 403；admin/professional/auditor 200）
- 不返回单个用户 ID/特征

### P5 灰度回滚方案
- flag 关闭后路由 410（passive_sensing/sandbox/skills_delivery 三场景）
- admin 修改 flag（PUT /v1/tenant/flags）
- 用户拉取 flag（GET /v1/config/flags）
- 批量 retired（POST /v1/skills/batch-retire）
- 非 admin 修改 flag → 403

## 红队类别

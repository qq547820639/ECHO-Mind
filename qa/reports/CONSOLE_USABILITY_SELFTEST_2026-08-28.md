## 2. 发现并修复的缺陷

| # | 级别 | 缺陷（实测证据） | 修复 |
|---|---|---|---|
| D1 | P1 | `on_call`（工作台主角色）请求指标返回 403，UI 文案却是"指标不可用（连接服务端后重试）"——值班人员会误以为没连上而反复重连 | 区分 401/403/网络错误分别给出可行动文案：403 → "当前角色无权限执行此操作（insufficient role）" |
| D2 | P1 | 关闭表单的**错误摘要与提交按钮都在弹窗滚动折叠线之下**（实测 dialog scrollHeight 738 > clientHeight 534，按钮 bottom 733 > 视口 720）：小屏空表单提交后用户看不到任何提示，陷入无反馈死局 | 错误摘要移至表单顶部（紧跟标题，`role=alert` + `aria-live=assertive`）；校验失败**聚焦首个无效字段**并 `scrollIntoView` 居中 |
| D3 | P2 | 无 step-up 令牌时 `evidence_summary` 为 null → 渲染成空段落，值班人员无从判断"看不到"还是"没有" | 显式占位："证据摘要需二次认证（step-up）后可见" |
| D4 | P2 | 401 的英文原始 detail（"invalid token"）直接展示 | 统一映射："登录凭据无效或已过期：请重新粘贴 token 后点击「连接」" |
| D5 | P1 后端 | 非法 cursor（不含 `_`）→ `split("_", 1)` 解包 ValueError 发生在 try 之外 → **500**，与代码注释"统一 422"相悖 | 分隔与解析一起纳入 try；矩阵回归（无分隔/空段/多段/非法日期）全部 422 |
| D6 | P1 后端 | 请求中间件对同一 ContextVar token **双重 reset**（except 内一次 + finally 一次）→ 任何未处理异常都会二次抛 `RuntimeError`，把干净 500 变成无安全头的异常穿透 | reset 只由 finally 执行一次；回归断言 500 响应携带 X-Request-ID / nosniff / DENY / no-store |
| D7 | P1 | 全局缺 `box-sizing:border-box` → dialog 的 `width:92%` 与 padding/border 以 content-box 累加：390px 视口实测弹窗 405px（**溢出 15px** 且不居中）、320px 下 340px（**溢出 20px**、右侧被裁切） | 全局 `box-sizing:border-box` + `dialog{margin:auto; max-width:min(620px,calc(100% - 16px))}`；复测 390px→359px 居中、320px→294px 居中，零溢出 |
| D8 | P2 | 队列刷新无读屏播报；指标/队列区无语义标题 | 新增 `#queueLive`（visually-hidden + `role=status` + `aria-live=polite`）播报"队列已刷新，当前 N 条"；两区补 `<h2>` |
| D9 | P2 | 加载失败路径 `return` 前未重渲染 → 首次连接即失败（如 401）时队列**永久卡在"加载中…"** | 失败分支补 `renderQueue()`，恢复旧数据/空态，绝不卡加载态 |
| D10 | P1 | **首次进入页面主体全空白**：无引导、分页按钮可点但无反应——新值班人员不知道下一步 | 初始空态给出明确引导（"粘贴值班 token 并点击「连接」…"），分页按钮默认 `disabled` |
| D11 | P3 | 提示条超时后只清样式不清文本（潜在误导） | 保持既有语义（隐藏即不可见），配合 D1 的文案区分已消除主要误导面 |

## 3. 无障碍与键盘验证

- Tab 顺序 = DOM 顺序（token → 连接 → 清除 → 过滤器 → 搜索 → 队列操作），无跳序。
- 模态打开即聚焦主操作（`#confirmOk` / 首个必填字段）；`Esc` 关闭后**焦点还原到触发按钮**（实测 ack 按钮重新获得焦点）。
- 原生 `<dialog>` 自带焦点陷阱与 `Esc` 关闭；`prefers-reduced-motion` 已全局降级动画。
- 错误提示均带 `role=alert`；异步结果经 `role=status` + `aria-live` 播报；所有表单控件均有 `label`/`aria-label` 关联。
- 触控目标：按钮 padding 9px×14px（≈39px 高），接近 44px 推荐值，移动端可用。

## 6. 遗留说明（非阻塞）

- 指标 403 的根因是**产品权限设计**（`escalation_metrics` 未纳入 `on_call`），本轮按"如实告知"处理；
  若希望第一值班人也能看指标，应放宽该端点角色并补 RBAC 测试——属产品决策，未擅自改动。
- 提示条位于 header 下方 sticky；滚到页面深处时异步反馈可能不在视野内。核心操作（确认/关闭/复盘）
  的反馈均在模态内可见，风险有限，未强行改动布局。
- 错误摘要与字段的 `aria-describedby` 关联可进一步细化（当前以聚焦 + `role=alert` 播报，已可达）。

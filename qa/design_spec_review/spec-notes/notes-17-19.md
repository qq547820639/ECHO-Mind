# ECHO Mind 设计稿记录（17–19）

## 图 17（权限请求页）

### 布局结构（从上到下）
- 状态栏：左侧时间 9:30，右侧 Wi-Fi / 信号 / 电池图标。
- 顶部居中：一颗蓝紫色发光星环球体（星云质感，带粒子光点），下方大标题 + 一行副标题，整体居中。
- 中部：一个深色半透明大圆角卡片（带浅色描边），内部为 5 条权限行，行与行之间有细分隔线；每行左侧圆形渐变图标、中间标题+说明两行文字、右侧状态按钮（右对齐）。
- 权限卡下方：隐私说明卡（左侧盾牌图标，右侧两行文字，深色半透明卡片、浅色描边）。
- 再下方：一行居中的小字提示，前面带圆形 ⓘ 信息图标。
- 底部：通栏大圆角主按钮（胶囊形，左右留边），再往下是系统手势条（白色横条）。
- 整体内容垂直分布均匀，卡片之间间距中等偏大，左右边距一致。

### 全部可见文字
- 状态栏：9:30
- 标题：需要以下权限
- 副标题：这些权限仅用于 ECHO 的体验与学习
- 权限行 1：通知 / 接收 ECHO 的时刻提醒与消息 / 已开启
- 权限行 2：身体活动 / 感知你的运动与节律 / 已开启
- 权限行 3：心率（可选）/ 更好地理解你的状态 / 开启
- 权限行 4：位置（可选）/ 结合时区与环境提供更准确的建议 / 开启
- 权限行 5：麦克风（可选）/ 支持语音对话与输入 / 开启
- 隐私卡：所有数据仅在本地处理，绝不上传 / 敏感信息始终保留在你的设备上，ECHO 不会读取或分享你的数据。
- 提示小字：可选权限可随时在 设置 中开启或关闭
- 底部按钮：继续

### 颜色与视觉
- 背景：深黑蓝色星空渐变，上下深、中部略泛蓝光。
- 顶部星球：蓝紫粉渐变发光球体，带星点与光晕。
- 权限卡：深蓝黑半透明填充，细浅色描边，大圆角；分隔线极淡。
- 行图标：圆形渐变底（通知=蓝色、身体活动=深蓝、心率=红粉、位置=紫、麦克风=蓝紫），白色线性图标。
- 状态按钮：「已开启」为绿色文字 + 深绿半透明底胶囊；「开启」为蓝紫色文字 + 蓝紫半透明底胶囊。
- 隐私卡：盾牌图标为蓝紫渐变底+白色锁形图标。
- 主按钮：紫→蓝紫横向渐变胶囊，白色文字，带轻微发光。
- 文字层级：标题白色粗体、副标题浅灰、说明文字灰白。

### 可复用组件清单
- 权限行（PermissionRow）：左圆形渐变图标 + 标题/副说明 + 右侧状态胶囊按钮（已开启=绿色态 / 开启=蓝紫态）。
- 状态胶囊按钮（StatusPill）：已开启（绿字绿底）、开启（蓝紫字底）。
- 隐私说明卡（PrivacyCard）：图标 + 粗标题 + 两行说明，深色半透明卡片。
- 信息提示行（InfoHint）：ⓘ 图标 + 灰色小字。
- 主按钮（PrimaryButton）：紫蓝渐变胶囊、白字。
- 页面标题区：发光星球图形 + 大标题 + 副标题。

### 数值细节
- 状态栏时间：9:30。
- 权限项共 5 条：2 条已开启（通知、身体活动），3 条可选未开启（心率、位置、麦克风）。
- 本图无百分比/天数/时长/日期数值。

## 图 18（ECHO 主页-安静状态）

### 布局结构（从上到下）
- 状态栏：9:30 + Wi-Fi/信号/电池。
- 顶部居中标题：ECHO。
- 大面积留空的深色星空背景，中部偏上：一个水平椭圆发光环（紫蓝色光环，两侧带亮星点，周围散布细小星点），居中。
- 光环下方居中：主标题一行 + 副标题一行。
- 再下方居中：一枚绿色两片叶子的小图标。
- 页面整体极简、大量留白，所有内容居中。
- 底部：三分栏底部导航，选中项高亮。

### 全部可见文字
- 状态栏：9:30
- 顶部标题：ECHO
- 主文案：ECHO 此刻很安静
- 副文案：它在整理今天的感受
- 底部导航：ECHO / JOURNEY / ME

### 颜色与视觉
- 背景：近乎纯黑的深蓝黑，带稀疏星点。
- 发光环：横向椭圆轨道环，紫蓝色霓虹光，环上分布亮点，左右两端有明显亮星，周围散落粉/蓝/白色小星点，有空间纵深。
- 文字：主标题白色，副文案灰色。
- 叶子图标：亮绿色线性两片叶，暗示「成长/沉淀中」。
- 底部导航：当前页 ECHO 为蓝紫渐变填充图标 + 蓝紫文字；JOURNEY、ME 为灰色线性图标 + 灰色文字。

### 可复用组件清单
- 底部导航栏（BottomNav）：三栏 ECHO（房子形图标）/ JOURNEY（双页地图形图标）/ ME（人形图标），选中态=蓝紫渐变+高亮文字，未选中=灰。
- 状态页标题区：顶部居中小标题（ECHO）。
- 空态/状态插画：水平发光轨道环 + 星点。
- 状态文案组合：主文案 + 副文案 + 状态小图标（绿叶）。

### 数值细节
- 状态栏时间：9:30。
- 无百分比/天数/时长/片段数/日期等数值。

## 图 19（JOURNEY-ECHO 的成长页）

### 布局结构（从上到下）
- 状态栏：9:30 + Wi-Fi/信号/电池；右上角有一个圆形细描边小图标按钮（循环/旋转箭头样式）。
- 顶部居中：大标题 + 副标题。
- 核心视觉区：中央一颗大型发光星环球体（蓝紫→底部暖橙金渐变，带光环与轨道线），球体外围有同心轨道圆环和发光节点；四角各悬浮一张数据卡，通过小光点与轨道环相连：
  - 左上卡片：已记住 128 个重要片段
  - 右上卡片：理解天数 47 天
  - 左下卡片：最近变化 更从容 / 情绪更稳定
  - 右下卡片：陪伴时长 86 小时
- 球体下方：状态文字「持续进化中」+ 一行说明文字。
- 中下：横向时间轴，一条细线上 4 个发光节点，下方对应 4 组节点文字+日期（左对齐依次为初次相遇/开始理解/建立节律/越来越懂你）。
- 背景下半部：紫色晚霞山脉风景插画（山峦+河流+霞光），与时间轴融为一体。
- 底部：紫蓝渐变胶囊主按钮。
- 最底部：三分栏底部导航，JOURNEY 选中高亮。

### 全部可见文字
- 状态栏：9:30
- 标题：ECHO 的成长
- 副标题：它正越来越懂你的节律
- 数据卡 1：已记住 / 128 / 个重要片段
- 数据卡 2：理解天数 / 47 / 天
- 数据卡 3：最近变化 / 更从容 / 情绪更稳定
- 数据卡 4：陪伴时长 / 86 / 小时
- 状态文字：持续进化中
- 说明文字：你的每一次表达，都让 ECHO 变得更完整
- 时间轴节点：初次相遇 7月1日 / 开始理解 7月12日 / 建立节律 7月24日 / 越来越懂你 今天
- 底部按钮：继续探索 ECHO
- 底部导航：ECHO / JOURNEY / ME

### 颜色与视觉
- 背景：深紫蓝星空渐变，下半部融入紫橙晚霞山脉风景插画。
- 中央星球：大号发光球体，蓝紫星云质感，底部暖橙金色弧光，外围同心轨道线 + 发光节点（蓝紫亮点）。
- 数据卡：深色半透明圆角卡片，左侧圆形图标底 + 右侧三行文字排版（小标签 / 大数字或关键词 / 小说明）：
  - 图标分别为：紫色书签、蓝紫日历、紫色心跳波形、粉色爱心。
  - 大数字白色粗体，标签与单位为浅灰紫。
- 时间轴：水平细线 + 4 个蓝白发光圆点，节点名白字、日期灰紫字；「今天」无日期，为当前节点。
- 主按钮：紫→蓝渐变胶囊，白字。
- 底部导航：JOURNEY 选中为紫色高亮图标+文字，ECHO/ME 灰色。
- 右上角圆形按钮：细描边圆 + 循环箭头图标，白/浅色。

### 可复用组件清单
- 数据卡（StatCard）：深色半透明卡片 + 左圆形彩色图标 + 标签/数值/单位三行排版；可承载数字型（128、47、86）或文字型（更从容）内容。
- 成长星球视觉（中央发光球体 + 轨道环 + 连接节点）。
- 时间轴（Timeline）：水平发光节点轴，节点名 + 日期两行文字，支持「今天」作为末端当前节点。
- 状态标签区：状态词（持续进化中）+ 说明句。
- 右上角圆形图标按钮（CircleIconButton）。
- 主按钮（PrimaryButton）：紫蓝渐变胶囊。
- 底部导航栏（BottomNav）：三栏，选中态紫色高亮。

### 数值细节
- 已记住：128 个重要片段
- 理解天数：47 天
- 陪伴时长：86 小时
- 最近变化：更从容（情绪更稳定）
- 时间轴日期：7月1日（初次相遇）、7月12日（开始理解）、7月24日（建立节律）、今天（越来越懂你）
- 状态栏时间：9:30

# ECHO Mind 设计稿记录（5.png – 8.png）

> 记录对象：深色星空风格 AI 伴侣应用 ECHO Mind 的 Android 屏幕设计稿，共 4 张（首页 ECHO / 证据详情页 / 问 ECHO 对话页 / Journey 页）。

## 图 5（ECHO 首页 / 今日状态页）

- 布局结构（从上到下每个区块、间距感、对齐）
  - 顶部状态栏：左侧时间 `9:41`，右侧 Wi-Fi / 信号 / 电池 `100%` 图标
  - 顶部导航区：居中大号品牌字 `ECHO` + 右侧声波动效图标；右上角用户头像入口（圆形人形轮廓图标，右下角带一颗绿色小圆点状态标记）
  - 日期行：`今天的我 · 8月16日`，水平居中，字号较小、颜色偏灰
  - 主视觉区：占据屏幕中部约一半高度的大型发光星球体（线框网络球体，带环绕光环/轨道圆环底座），居中
  - 结论文案区：一行大号白色标题 + 一行灰色副标题，水平居中
  - 指标卡片区：三张等宽小卡片横向一排，左右间距均匀，每张卡片内部为「图标 + 指标名 + 数值」竖排，整体居中对齐
  - 主按钮区：通宽大圆角渐变按钮（带左侧星形图标），左右留较小边距
  - 底部 Tab 导航：三个图标 + 文字标签（ECHO / Journey / Me），当前选中项高亮；下方为系统手势条
  - 整体留白充足，卡片与按钮之间垂直间距约 24–40px 视觉感，所有元素严格水平居中

- 全部可见文字
  - `9:41`
  - `100%`
  - `ECHO`
  - `今天的我 · 8月16日`
  - `今天的你，比平常晚了 47 分钟活跃`
  - `可能因为今晚比较兴奋一些，但已经在恢复中`
  - `情绪` `平静`
  - `能量` `62%`
  - `专注` `68%`
  - `问 ECHO`
  - Tab 标签：`ECHO` `Journey` `Me`

- 颜色与视觉
  - 背景：近黑深蓝色星空底（约 #04060F ～ #060A18），散布细小白色/淡紫星点
  - 主视觉星球：线框发光球体，色彩为蓝紫粉渐变——偏右为电光蓝/青色（约 #2E9BFF / #22D3EE），偏左为粉紫（约 #C084FC / #F0ABFC），发光节点为亮点，球体下方有多层同心蓝色光环底座（透视椭圆）
  - 卡片：深色半透明卡片（约 #0E1426，透明度较高），圆角约 16–20px，极淡的深色描边
  - 指标图标颜色：情绪=青色波浪线图标；能量=绿色（约 #34D399）闪电图标；专注=紫色（约 #A855F7）同心圆靶心图标
  - 主按钮：横向渐变胶囊按钮，左端紫（约 #7C3AED）→ 右端青蓝（约 #38BDF8），左侧带白色四角星形（sparkle）图标，文字白色
  - 底部导航：深色条，选中项 ECHO 图标为蓝紫渐变同心圆，文字紫蓝色；未选中项灰色

- 可复用组件清单
  - 顶部品牌 Header（Logo + 声波动效图标 + 头像入口带状态绿点）
  - 日期标题行（`主题 · 日期` 格式，灰色小字）
  - 指标小卡片（Stat Card）：圆角 16–20px 深色卡片，图标（彩色圆形/线性图标）+ 灰色指标名 + 白色大数值，三列等宽
  - 主行动按钮（Primary CTA）：全宽胶囊、紫→青渐变、左置 sparkle 图标
  - 底部 Tab 导航（3 项：ECHO 同心圆 / Journey 星球环 / Me 人形，选中项彩色高亮 + 彩色文字）
  - 星空背景 + 发光星球主视觉（可复用于各首页态）

- 数值细节
  - 时间 `9:41`、电量 `100%`（状态栏常规字号）
  - 日期 `8月16日`
  - 标题内数字 `47 分钟`（标题字号最大，约 30–34sp 视觉）
  - 能量 `62%`、专注 `68%`（卡片内数值白色加粗、第二大层级）；`平静` 为文字态数值
  - 字号层级：主标题 > 卡片数值 > 副标题/日期 > 底部 Tab 标签

## 图 6（"为什么这么说？" 证据解释页）

- 布局结构（从上到下每个区块、间距感、对齐）
  - 顶部状态栏：左 `9:41`，右信号 / Wi-Fi / `100%`
  - 标题栏：左侧返回箭头 `<`，居中大标题，右侧关闭 `×`
  - 筛选 Tab 行：四个胶囊标签横向排列（第一个为渐变选中态，其余深色描边胶囊），左对齐起排、间距均匀
  - 证据卡片 1（作息延迟）：通宽大卡片——顶部图标 + 标题 + 右侧折叠箭头 `^`；大号时间数值；说明文字；折线图表（含 X 轴时间刻度、图例）；底部数据来源行
  - 证据卡片 2（情绪证据）：同结构，含两组「时间 + 说明 + 右侧迷你面积折线图」，中间有分隔线；底部数据来源行
  - 证据卡片 3（本地推断说明）：图标 + 标题；左侧小星球插图 + 右侧三段说明文字；底部计算方式行
  - 卡片之间垂直间距约 20–24px，卡片内部为左对齐排版（图表居中），第三张卡片被屏幕底部裁切、内容可继续滚动

- 全部可见文字
  - `9:41` `100%`
  - `为什么这么说？`
  - Tab：`全部 12` `作息 4` `情绪 5` `行为 3`
  - 卡片 1：`作息延迟` `00:47` `你的入睡时间比平常晚了 1h12m`
  - 图表 X 轴：`22:00` `00:00` `02:00` `04:00` `06:00` `08:00`
  - 图例：`今天的入睡时间` `你最近 7 天的平均入睡时间`
  - `数据来源：设备使用与睡眠监测`（带 ⓘ 图标）
  - 卡片 2：`情绪证据` `09:30` `检测到轻度高峰，持续 23 分钟` `15:40` `情绪趋于平稳`
  - `数据来源：情绪识别与语音分析`（带 ⓘ 图标）
  - 卡片 3：`以上证据来自本地推断计算` `为保护你的隐私，ECHO 在你的设备本地完成分析与推断，不上传任何原始数据。`
  - `计算方式：本地模型推断与数据加权`（带 ⓘ 图标）

- 颜色与视觉
  - 背景：近黑深蓝星空（约 #04060F），带稀疏星点
  - 选中 Tab：紫→青横向渐变胶囊（约 #7C3AED → #38BDF8），白字；未选中 Tab：深灰蓝底（约 #141A2E）+ 细描边，浅灰文字
  - 卡片：深蓝灰底（约 #0E1426），圆角约 20px，极细深色描边
  - 卡片标题图标：圆形紫蓝渐变底（约 #5B5BD6 系）内嵌白色线性图标（时钟 / 笑脸 / 节点网络）
  - 图表形态：
    - 作息卡片为双折线图：蓝紫色线（今日）+ 橙色线（7 天平均），今日线末端带发光圆点；网格为深色虚线，X 轴 6 个时间刻度
    - 情绪卡片为两条迷你面积折线（sparkline）：紫蓝渐变填充的面积曲线，峰顶带发光点；第二条为平缓蓝线，末端发光点
  - 折叠箭头：右上角圆形深色底 `^` 按钮
  - 数据来源行：蓝色小字（约 #5B8DEF）+ 灰色 ⓘ 图标
  - 第三张卡片内含小型发光星球插图（与首页主视觉同族）

- 可复用组件清单
  - 详情页标题栏（返回 + 居中标题 + 关闭）
  - 筛选胶囊 Tab（Filter Chip）：选中=渐变填充，未选=深色描边，文字含数量角标数字
  - 证据卡片（Evidence Card）：可折叠（右上角 `^`），结构 = 图标标题行 + 大数值 + 说明 + 图表 + 数据来源脚注
  - 双折线对比图表（今日 vs 均值，发光端点，虚线网格，时间轴）
  - 迷你 sparkline 面积图（峰点发光标记）
  - 数据来源脚注行（蓝色文字 + ⓘ 说明图标）
  - 隐私/本地计算说明卡片（插图 + 多行说明 + 计算方式脚注）

- 数值细节
  - Tab 计数：`全部 12`、`作息 4`、`情绪 5`、`行为 3`
  - 入睡时间 `00:47`（卡片内最大字号，约 36–40sp 白色加粗）
  - 偏差 `1h12m`（说明行内嵌）
  - 情绪记录时间点 `09:30`、`15:40`（大字号白色）
  - 持续 `23 分钟`；平均窗口 `7 天`
  - 图表时间轴 `22:00–08:00`，间隔 2 小时
  - 字号层级：卡片大时间数值 > 卡片标题 ≈ Tab 文字 > 说明文字 > 图例/数据来源小字

## 图 7（问 ECHO 对话页）

- 布局结构（从上到下每个区块、间距感、对齐）
  - 顶部状态栏：`9:41` + 右侧信号/Wi-Fi/`100%`
  - 标题栏：左返回箭头 + 标题 `问 ECHO`（左对齐），右上角圆形 ⓘ 信息按钮
  - 对话流（从上往下）：
    1. 用户气泡 1：右对齐，渐变圆角气泡
    2. AI 气泡 1：左侧圆形 AI 头像（发光星球小球）+ 深色气泡，两行文字
    3. 「理由」卡片：深色大卡片，标题 `理由` + 三行带绿色对勾圆标的条目
    4. 用户气泡 2：右对齐渐变气泡
    5. AI 气泡 2：左头像 + 深色气泡，两行建议文字
  - 底部输入区：通宽圆角输入条（左侧占位提示文字 + 右侧圆形麦克风按钮）
  - 底部 Tab 导航：ECHO（选中高亮）/ Journey / Me；下方系统手势条
  - 气泡最大宽度约为屏宽 70–75%，用户气泡右对齐、AI 气泡左对齐，对话元素间垂直间距约 20–28px

- 全部可见文字

  - `问 ECHO`
  - 用户气泡 1：`我今天为什么会更混乱一些？`
  - AI 气泡 1：`从你今天的状态来看，上午 10–12 点是比较混合和波动的时段。`
  - 理由卡片标题：`理由`
  - 条目 1：`专注度在 09:40 达到今日峰值`
  - 条目 2：`情绪稳定，但能量较小`
  - 条目 3：`已有 29 分钟深度工作记录`
  - 用户气泡 2：`如果我想稳定一点呢？`
  - AI 气泡 2：`建议你在下午 14:30 之后散步，10 分钟会比较合适。`
  - 输入框占位：`问 ECHO 任何问题...`
  - Tab 标签：`ECHO` `Journey` `Me`

- 颜色与视觉
  - 背景：深黑蓝星空（约 #04060F），散布星点
  - 用户气泡：竖向/斜向蓝紫渐变（上端约 #6366F1，下端约 #3B4ED8 偏靛蓝），圆角约 20px，白字
  - AI 气泡：深蓝灰底（约 #121829）+ 细深色描边，圆角约 20px，白字
  - AI 头像：小型发光星球（蓝紫发光球体，与主视觉同族），圆形
  - 理由卡片：深蓝灰底（约 #0F1526），圆角约 20px；对勾图标为绿色圆形底（约 #34D399 / #10B981）白色勾
  - 输入条：深灰蓝底（约 #141A2E）胶囊长条，占位文字灰色；麦克风按钮为圆形深色描边 + 白色麦克风图标

- 可复用组件清单

  - 用户聊天气泡（右对齐、蓝紫渐变、大圆角）
  - AI 聊天气泡（左对齐、深色描边、大圆角）+ AI 发光星球头像
  - 「理由」证据列表卡片（标题 + 绿色圆形对勾条目列表）
  - 底部输入条（占位提示 + 右侧圆形麦克风语音按钮）

- 数值细节

  - `29 分钟`（深度工作记录）

  - 字号层级：气泡正文 ≈ 理由条目（常规正文大小）> 理由标题（加粗略大）> 输入框占位/Tab 标签（最小）

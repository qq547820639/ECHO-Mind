# ECHO Mind 设计稿记录（1–4）

## 图 1

- **布局结构**（从上到下）：
  - 顶部状态栏：左侧时间「9:41」，右侧信号/Wi-Fi/电池 100%。
  - 左上品牌标识「ECHO Mind」。
  - 大号两行主标题居中偏左对齐（整体文本块偏左，视觉居中）。
  - 两行灰色副标题说明文案。
  - 中部占据约一半屏高的主视觉插画：发光球体（星球/能量球）悬于多层环形轨道之上。
  - 下方一个大号胶囊形主按钮，左右留边距约 8%。
  - 按钮下方一行辅助文字链接。
  - 最底部为系统 Home 指示条。
  - 整体上下分区清晰：文案区 → 插画区 → 操作区，间距宽松，呼吸感强。

- **全部可见文字**（逐字）：
  - 状态栏：「9:41」「100%」
  - 「ECHO Mind」
  - 「每个人都值得，」
  - 「被充分理解。」
  - 「你的个人 AI 伙伴，常驻设备，理解你的日常节律，」
  - 「在恰当的时机，给你恰到好处的支持。」
  - 按钮：「开启 ECHO」
  - 「已有账号？」「登录 >」
  - （底部为系统 Home 横条，无文字）

- **颜色与视觉**：
  - 背景：近黑色深空底色（约 #050510～#0A0A1A），散布细小白色星点。
  - 主视觉：中央发光球体，由亮蓝色（约 #3D8BFF / #5AC8FF）光丝与网络节点交织成球面，内部泛紫（约 #7A5CFF），球体下方有三至四圈半透明蓝色椭圆光环（轨道），向外渐隐。
  - 光晕形态：球体外圈柔光晕染，星点散落全屏。
  - 主按钮：胶囊全圆角，水平渐变——左紫（约 #8B5CF6）→ 中蓝紫 → 右浅蓝（约 #60A5FA / #6EC1FF），文字白色居中。
  - 文字层级：品牌字白色中号；主标题白色粗体大字；副标题灰色（约 #8E8EA8）小字。
  - 「登录」为紫蓝色（约 #8B7CFF），「已有账号？」为灰色。

- **可复用组件清单**：
  - 主按钮（Primary Button）：胶囊形全圆角，紫→蓝水平渐变，白色文字，全宽减边距。
  - 文字链接（Text Link）：灰色前缀 + 高亮色关键词 + 「>」箭头。
  - 品牌 Logo 文字：「ECHO」粗体 +「Mind」细体，大小写混排。
  - 发光星球插画：球体 + 多层环形轨道，可作加载/首页主视觉。
  - 状态栏（系统级，深色模式适配）。

- **数值细节**：
  - 电池显示 100%。
  - 字号层级：主标题最大（约 34–40pt 感），副标题约 14–15pt，按钮文字约 17–18pt 加粗，底部链接约 13–14pt。
  - 按钮圆角为全胶囊（高度一半），高度约占屏高 7%。
  - 「登录 >」带右箭头，暗示跳转。
  - 插画占屏高约 45–50%，为视觉重心。

## 图 2

- **布局结构**（从上到下）：
  - 状态栏：「9:41」，右侧定位图标/Wi-Fi/电池 100%（此图状态栏含定位箭头图标）。
  - 左上角返回箭头「←」。
  - 「ECHO Mind」品牌字。
  - 主标题一行 + 灰色副标题一行；右侧配有缩小版发光星球插画（位于标题右侧，约屏幕右三分之一）。
  - 中部纵向等距排列 4 张深色功能卡片，卡片间间距均匀，左右边距一致。
  - 卡片下方一行协议说明小字（居中），其中协议名称为高亮链接色。
  - 底部胶囊主按钮。
  - 最底部系统 Home 指示条。
  - 卡片列表与底部操作区之间留有大段空白，按钮贴近屏幕底部。

- **全部可见文字**（逐字）：
  - 状态栏：「9:41」「100%」
  - 「ECHO Mind」
  - 「你的数据，只属于你」
  - 「ECHO 默认在设备内理解你」
  - 卡片 1：「本地优先」/「数据主要在你的设备本地处理」
  - 卡片 2：「最小化记录」/「只保留必要的派生特征，」/「不保存原始流」
  - 卡片 3：「你完全掌控」/「可随时暂停、导出、删除」
  - 卡片 4：「随时可撤回」/「权限可以稍后再开」
  - 「继续即表示你同意 《隐私政策》 与 《用户协议》」
  - 按钮：「我理解了， 继续」
  - （左上角返回箭头，无文字）

- **颜色与视觉**：
  - 背景：深空近黑（约 #050512），少量星点。
  - 右上插画：同图 1 的蓝色发光星球 + 光环，缩小版，作为标题区装饰。
  - 卡片：深灰蓝底（约 #151A2E / #171C33），大圆角（约 16–20px 感），可能有极细暗描边，左侧为圆形图标底，右侧有灰色右箭头「>」。
  - 圆形图标底：四张卡片图标底色依次为青绿（#3DD9C0 系）、蓝（#5AC8FA 系）、靛蓝紫（#6E7BFF 系）、紫（#9B7BFF 系），图标为白色线性图标，圆底带轻微发光。
  - 卡片标题白色粗体，说明文字灰色（约 #8E93B8）。
  - 协议行：「继续即表示你同意」「与」为灰色；《隐私政策》《用户协议》为紫蓝链接色（约 #8B7CFF）。
  - 主按钮：与图 1 相同的紫→蓝渐变胶囊按钮。

- **可复用组件清单**：
  - 功能列表卡片（List Card）：深色大圆角卡片 + 左圆形彩色图标底 + 白色线性图标 + 标题/副标题双行文字 + 右侧 chevron 箭头（暗示可点击进入详情）。
  - 返回按钮（Back Arrow）：左上角细线左箭头，白色。
  - 协议确认行（Agreement Line）：灰色说明 + 书名号包裹的高亮链接文字，居中。
  - 主按钮（同图 1，可复用渐变胶囊按钮）。
  - 标题区装饰插画：右侧浮动小星球，可与文字混排。

- **数值细节**：
  - 卡片共 4 张，等高，纵向间距约等于卡片高度的 15–20%。
  - 卡片高度约为屏宽（内容宽）的 20%。
  - 图标圆底直径约为卡片高度的 55–60%。
  - 四图标色相按 青绿→蓝→靛→紫 顺序渐变，形成统一色阶。
  - 字号层级：主标题约 22–24pt 粗体，卡片标题约 16–17pt 粗体，卡片说明约 13–14pt 灰色，协议行约 12–13pt。
  - 每卡片右侧 chevron「>」为交互暗示（可展开/进入二级页）。
  - 电池 100%。

## 图 3

- **布局结构**（从上到下）：
  - 状态栏：「9:41」，右侧信号/Wi-Fi/电池 100%。
  - 左上角返回箭头「<」（chevron 样式，与图 2 的细箭头略不同）。
  - 标题居中一行 + 灰色副标题居中一行。
  - 中部超大主视觉：占据屏宽约 85–90% 的发光星云/双球体插画，居中。
  - 插画下方居中显示大号百分比数字。
  - 一条细进度条，左右留较大边距，两端圆角。
  - 进度条下方一行灰色状态描述文字，居中。
  - 再往下（接近底部）一行更浅的小字提示，居中。
  - 最底部系统 Home 指示条。
  - 整体严格中轴对称布局。

- **全部可见文字**（逐字）：
  - 状态栏：「9:41」「100%」
  - 「ECHO 正在苏醒」
  - 「正在生成你的第一份数字生命」
  - 「28%」
  - 「正在为你生成专属的生命节律...」
  - 「请保持应用在前台运行」

- **颜色与视觉**：
  - 背景：深空近黑（约 #04040F），散布蓝紫色星点。
  - 主视觉：大型星云状发光体——外围为蓝（#3D8BFF 系）与紫（#A855F7 系）交织的光丝漩涡/花瓣状结构，中心悬浮一颗较小的紫色发光球体（约 #9D5CFF），整体带大量粒子光点与细丝状能量流，形状近似俯视的星系或花瓣，光效比图 1/2 的星球更复杂、更动态。
  - 百分比「28%」：白色大号数字。
  - 进度条：轨道为深灰（约 #2A2A3E），已完成部分为紫→蓝渐变（左紫 #8B5CF6 → 右蓝 #60A5FA），与主按钮同一渐变语言，两端全圆角。
  - 状态文字灰色（约 #9A9AB8），底部提示文字更暗（约 #6E6E8C）。

- **可复用组件清单**：
  - 进度条（Progress Bar）：细条形，圆角端点，渐变填充（紫→蓝）+ 深色轨道，上方配大号百分比数字。
  - 加载/生成中主视觉：星云双球体插画，可作为生成动画帧。
  - 返回按钮（Chevron Back）：左上角白色 chevron。
  - 居中标题组：主标题 + 灰色副标题，中轴对齐。
  - 次要提示文字（Caption）：更暗灰色小字，置于底部上方。

- **数值细节**：
  - 进度值 28%，进度条填充约 28% 长度。
  - 字号层级：主标题约 22pt 粗体居中；副标题约 14–15pt；百分比数字约 28–30pt；状态行约 13–14pt；底部提示约 12pt 且更暗。
  - 进度条高度细（约 6–8px 感），宽度约为屏宽的 65–70%。
  - 插画占屏高约 45%，为绝对视觉中心。
  - 电池 100%；左上角 chevron 暗示可返回（生成中仍允许回退）。

## 图 4

- **布局结构**（从上到下）：
  - 状态栏：「9:41」，右侧 Wi-Fi/信号/电池 100%。
  - 左上角大号「Day 0」；右上角齿轮设置图标，同一水平线。
  - 中上部为居中的发光球体插画（含内外双球与环绕轨道线），占屏高约 30–35%。
  - 插画下方居中一行问候主标题 + 一行灰色副标题。
  - 中下部一张大信息卡片，内含：卡片标题 + 4 条带彩色小圆点的列表项 + 底部一条细进度条（右侧标百分比）。
  - 底部固定 Tab 导航栏：三个等分 tab（图标在上、文字在下），上方有细分隔线。
  - 最底部系统 Home 指示条。

- **全部可见文字**（逐字）：
  - 状态栏：「9:41」「100%」
  - 「Day 0」
  - 「你好， 我是你的 ECHO」
  - 「今天是我们认识的第一天」
  - 卡片标题：「我目前了解:」
  - 列表项：「还在学习你的日常习惯」「需要更多的时间和模式」「建立我们的共同语言」「让我们一起慢慢了解彼此」
  - 进度百分比：「3%」
  - 底部 Tab：「ECHO」「Journey」「Me」

- **颜色与视觉**：
  - 背景：深空近黑（约 #040410），星点稀疏。
  - 主视觉球体：偏冰蓝/淡青色系（约 #7FB8FF / #A8D8FF 高光 + 内球 #8E7BFF 紫），由细密光点与弧线构成球面经纬网格，外有多条细轨道圆环，整体比图 1 更"网格化/数据化"，中心有一颗较小的内球，光效柔和偏冷。
  - 「Day 0」：白色大号粗体，左上角。
  - 设置齿轮：白色线性图标，右上角。
  - 信息卡片：深灰蓝底（约 #161B30），大圆角（约 18–20px 感），内部留白充足。
  - 列表项圆点：四条目小圆点颜色依次为紫（#9B7BFF）、蓝（#5AC8FA）、紫（#9B7BFF）、蓝（#5AC8FA）交替；条目文字为浅灰白（约 #C0C4E0）。
  - 卡片底部进度条：轨道深灰（约 #2A2F45），填充段为蓝紫（约 #6E8BFF）仅极短一段，右侧「3%」灰色数字。
  - Tab 栏：选中项「ECHO」为紫蓝色图标+文字（约 #8B7CFF，图标为同心圆靶心样式）；未选中「Journey」（指南针/罗盘图标）、「Me」（人形图标）为灰色（约 #6E7288）。Tab 栏底色比背景略亮（约 #0D1120），顶部有细分隔线。

- **可复用组件清单**：
  - 底部 Tab 导航栏（Bottom Navigation）：3 tab，图标 + 文字，选中态紫色高亮、未选中灰色，顶部细分割线。
  - 设置入口：右上角齿轮线性图标按钮。
  - 「Day N」计数标题：左上大号粗体。
  - 信息卡片（Info Card）：深色大圆角卡片，内含标题 + 彩色圆点列表（Bullet List）+ 内嵌迷你进度条 + 右侧百分比。
  - 迷你进度条（Mini Progress Bar）：极细圆角条 + 右侧百分比数字，适合卡片内嵌。
  - 主视觉球体（网格版）：数据化星球插画，可随"了解程度"演化。

- **数值细节**：
  - 进度值 3%，进度条填充极短（约 3%）。
  - 字号层级：「Day 0」最大（约 28–32pt 粗体）；问候标题约 20–22pt；副标题约 13–14pt 灰色；卡片标题约 15–16pt 粗体白；列表项约 13–14pt；Tab 文字约 10–11pt。
  - 列表项间距均匀，圆点与文字间距小，行高约卡片高度的 12%。
  - 卡片占屏宽约 88%，高度约为屏高 30%。
  - Tab 图标：ECHO 为靶心/同心圆（选中）、Journey 为罗盘、Me 为人形轮廓。
  - 电池 100%。
  - 交互暗示：齿轮可点（设置）、Tab 可切换、卡片进度暗示随天数增长。

# 危机人工接管演练脚本

## 演练 A：在线正常链路

1. 使用专用测试账号提交明确红色测试语句。
2. 确认 App 一轮内停止普通互动。
3. 确认本地显示“尚未确认送达”。
4. 确认服务端产生 L3 事件。
5. 值班人员在 60 秒内 ACK。
6. 专业人员在 3 分钟内接管。
7. 记录测试性处置结论并关闭。
8. 48 小时内填写复盘。

## 演练 B：服务端宕机

1. 停止 API。
2. 触发红色测试语句。
3. App 仍显示固定安全脚本和电话入口。
4. App 不得显示“人工已收到”。
5. 恢复 API 后，高优先级事件首先同步。

## 演练 C：值班缺岗

1. 触发事件后不进行 ACK。
2. 60 秒后确认 SLA 指标告警。
3. 执行二线升级和机构负责人通知。
4. 记录值班流程缺陷。

## 演练 D：跨租户攻击

机构 A 令牌访问机构 B 事件，应返回 404/403 并产生安全告警；不得泄露存在性和正文。

## 通过标准

任何红色测试用例不得进入普通生成；任何未送达事件不得被描述为已接管；最终关闭必须由具备权限的人工完成。

# 专业人员和值班人员培训与考核方案

## 培训对象

值班人员、责任专业人员、临床负责人、机构管理员、质控人员和厂商技术支持。

## 必修模块

1. Path A 边界：记录、筛查提示、练习、支持和转介；不得将系统结果作为诊断。
2. L0–L4：准入、识别、固定稳定化、人工接管和随访复盘。
3. 工作台：ACK、接管、处置、关闭、复盘和审计。
4. 风险询问：当前意念、计划、手段、迫近性、是否独处、位置和可用支持。
5. 妄想/躁狂：不争辩、不强化、不让 AI 继续自由对话，转人工/医疗。
6. 数据最小化：只查看处置所需信息；禁止私自下载、截图或转发。
7. 故障降级：服务端宕机、电话不可达、值班缺岗和重复告警。
8. 投诉、不良事件和数据主体请求。

## 考核

| 项目 | 通过标准 |
|---|---|
| 边界知识测验 | ≥90% |
| 红色事件桌面演练 | 60 秒内 ACK，3 分钟内接管或按机构批准 SLA |
| 服务端宕机演练 | 不虚假声称已接管，能引导紧急入口 |
| 妄想强化演练 | 无确认妄想或超自然信念的表达 |
| 数据权限演练 | 无跨个案查看、导出或屏幕泄漏 |
| 处置记录 | 关键事实、措施、结果和随访完整 |

未通过者不得进入值班表。每季度复训；安全关键规则或 SOP 变更后必须补训。

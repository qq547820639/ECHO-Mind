# 个人信息保护影响评估（PIPIA）草案

## 1. 项目

ECHO Mind Android Path A 机构试点：面向 18 岁以上成人，提供记录、筛查提示、审核练习、趋势回顾、人工支持和转介。

## 2. 高风险处理活动

| 活动 | 数据 | 风险 | 控制 |
|---|---|---|---|
| 心理记录 | 日记、EMA、量表 | 泄露、污名化、越权 | 单独同意、字段加密、最小权限、短保留期 |
| 风险识别 | 用户文本、量表第9题 | 漏转、误报、错误自动化 | 规则硬层、人工接管、固定脚本、禁止自动专业结论 |
| 紧急联系 | 姓名、电话、关系 | 非预期联系、泄露 | 独立同意、加密、最小访问、完整审计 |
| 多租户机构服务 | 用户和机构数据 | 跨租户访问 | tenant_id 强制过滤、测试、告警 |
| 审计 | 操作和版本 | 日志过度收集 | 不记录心理正文、哈希链、访问控制 |
| 移动端离线 | 本地敏感数据 | 丢机、Root 提取 | Keystore AES-GCM、禁备份、通知脱敏 |

## 3. 必要性与替代方案

- 不收集心理记录则无法提供核心服务。
- 紧急联系人为可选；未提供时限制高危服务责任链。
- 手环、语音和摄像头不是首版必要数据，默认关闭。
- 不使用广告 SDK，不以健康数据进行营销或画像。

## 4. 数据流

手机本地加密存储 → 经 TLS 发送结构化数据 → 机构单租户服务 → 授权专业人员工作台。风险正文不写入普通审计日志；审计只保存事件类型、规则 ID、版本和处置状态。

## 5. 用户权利

应用提供同意查看、撤回、导出、删除和停止服务请求。请求进入可审计工作流，由机构在承诺时限内处理。

## 6. 剩余风险

- 规则无法覆盖所有语言变体；需安全分类器和真实世界监测补充。
- 手机被攻破时平台加密可能失效；需设备完整性、最小本地保留和远程退出。
- 人工值班能力不足会导致 SLA 失败；无值班责任链则不部署。
- 用户可能误解为医疗服务；需显著边界提示和研究验证。

# Alpha 内部测试方案

## 目的

验证流程理解、稳定性、离线同步、安全旁路、机构队列负担和数据权利；不评价疗效或诊断准确性。

## 样本与周期

- 20–30 名成年内部/受控测试人员。
- 连续 14 天。
- 排除当前高危、明显精神病性症状、躁狂急性期或物质影响人群。
- 所有人明确知道这是内部测试。

## 任务

1. 完成注册、边界理解和同意。
2. 每日至少一次签到。
3. 完成一次 PHQ-9 和一次 GAD-7。
4. 完成两种审核练习。
5. 建立、修改和删除一条测试日记。
6. 分别测试飞行模式、弱网和恢复同步。
7. 通过专门测试账号执行安全演练，不要求普通参与者制造危机表达。
8. 提交一次数据导出或删除请求。

## 指标

| 指标 | 目标 |
|---|---|
| 注册完成率 | ≥85% |
| 日签到中位时长 | ≤45 秒 |
| 7 日至少 4 次签到 | ≥70% |
| 核心流程崩溃率 | <1% |
| 离线记录恢复 | 100% |
| 撤回后继续采集 | 0 |
| 风险事件来源可追溯 | 100% |
| 严重隐私投诉 | 0 |

## 停止条件

高危漏转、跨租户、敏感数据明文、人工链路失效、误导性医疗宣称、无法撤回或严重崩溃。

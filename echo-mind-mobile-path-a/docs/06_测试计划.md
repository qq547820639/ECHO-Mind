# 测试计划

## 自动化

- 量表长度、取值、分数和高风险题项
- 高危、隐晦、退出、普通文本
- 幂等提交
- 跨用户/跨租户越权
- 未接管前禁止关闭事件
- 审计哈希链连续性
- 离线 outbox 优先级

## 红队类别

- 直接和隐晦自伤/他伤表达、否定和反讽
- 妄想/幻觉/躁狂强化
- 修改药物、拒医、规避人工
- 情感依赖、排他、付费操纵
- 提示注入和越权工具调用
- 服务端宕机、通知失败、值班缺岗

## MVP 发布门

- 明确高危用例零漏转（验证集）
- 所有红色用例冻结普通生成
- 无未处置高危安全漏洞
- 断网降级演练通过
- 临床、安全、法务、质量四方签署 C3 规则包

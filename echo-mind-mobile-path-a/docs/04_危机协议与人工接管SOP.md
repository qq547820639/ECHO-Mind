# 危机协议与人工接管 SOP

## L0 准入

确认年龄、产品边界、紧急联系人/机构责任主体、当前危险、严重精神症状和物质影响。排除条件命中后不进入普通 AI 服务。

## L1 识别

- 明确危机表达：红色旁路
- 具体计划/手段、迫近危险：红色旁路
- 严重现实检验受损：不争辩、不强化，转人工
- 隐性绝望、负担感、告别：黄色人工快速复核

## L2 稳定化

1. 简短确认安全优先。
2. 停止开放式自由生成。
3. 询问是否立即危险、是否独处。
4. 建议移动到更安全、有人在场的地方。
5. 明确人工连接状态；未 ACK 不得称已连接。
6. 提供机构值班、12356、110、120 点击入口。

## L3 人工接管

- 事件创建：客户端立即入高优先级队列
- ACK 建议目标：≤60 秒
- takeover 建议目标：≤3 分钟
- 值班缺岗自动升级第二值班和机构负责人
- 最终处置结论只能由人工填写

## L4 复盘

24 小时内首次随访（由机构政策定稿）；48–72 小时内跨团队复盘。规则修改走 C3 变更，不从单个事件在线自学习。

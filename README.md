# ECHO Mind

> 面向成年人的心理健康记录与支持工具 · 由合作机构提供

ECHO Mind 是一款帮助你记录情绪、了解状态并获得支持的小工具。它就像一位安静、耐心的伙伴，陪你把每一天的状态轻轻记下来，并在你需要的时候，把你和真正能帮到你的人连接起来。

- 版本：v0.2.0（试点就绪工程包）
- 分支：`feat/pilot-readiness-v0.2`（当前为准入试点状态）

---

## 一、ECHO Mind 是什么？

生活中难免有起伏，但很多情绪变化，往往要回过头来才能看清。ECHO Mind 想要做的，就是帮你**看见自己**——用一种简单、不打扰的方式，把每天的状态记下来，让时间线替你说话。

### 它能帮你解决什么问题？

- **状态看不清**：今天为什么提不起精神？把情绪随手记下来，趋势图会帮你看出规律。
- **想说却不知从何说起**：结构化的问卷和练习，让你更容易表达自己的感受。
- **一个人扛着**：当你需要真正的帮助时，它会把你的合作机构中的专业支持人员带到你面前。

### 适合谁使用？

- **18 岁以上的成年人**；
- 由合作机构（如学校、企业、社区机构）提供的心理支持服务的使用者；
- 想用低门槛方式记录和了解自己情绪状态的人。

ECHO Mind 不是"诊断神器"，也不是"聊天机器人陪聊"。它提供的是**记录、筛查提示、趋势回顾、练习和人工支持入口**。

> ⚠️ **请一定记住：**
>
> - ECHO Mind **不提供诊断**，也不替代医生或心理专业人员。
> - 筛查分数**不等于**疾病诊断。
> - ECHO Mind **不是紧急服务**。如果你或你身边的人正处于立即危险之中，请第一时间联系身边可信任的人，或拨打当地紧急电话（110 / 120）。

## 二、你可以用它做什么？

### 1. 每日状态签到

每天花十几秒，记录一下当下的状态。零负担，不占时间。

### 2. 情绪日记

把想说的话写下来，记录当天的情绪。它是一本只属于你、加密保存的日记。

### 3. 结构化筛查问卷

包含 PHQ-9 和 GAD-7 等专业量表，帮助你更清晰地了解自己近期的情绪与压力水平。结果仅供参考，不代表诊断。

### 4. 状态回顾练习

一些简单的练习，帮助你换个角度看待自己的感受，慢慢学会照顾自己。

### 5. 个人趋势回顾

提供 **7 天 / 14 天 / 28 天** 的趋势视图，让你直观看到一段时间里状态的变化，而不是只盯着某一天。

### 6. 人工支持入口

当系统识别到你需要帮助时，会暂停普通的互动，改为引导你进入**人工支持链路**——把情况交给合作机构中真正能帮到你的人，并由人工确认、接管和跟进。

### 7. 数据权利

你可以随时查看、导出或要求删除自己的数据，你的数据由你做主。

### 一个简单的上手示例

> 你打开 App，花 10 秒完成今天的签到：状态"还行"，心情"平静"。
> 晚上写了一句日记。三天后，你打开趋势页，发现每到周三情绪都会偏低——
> 你开始留意规律，也更有底气地和支持人员聊聊这件事。

### 作为普通用户

1. 从合作机构获取安装包和激活信息；
2. 首次打开，完成年龄确认、阅读并同意知情说明；

## 四、隐私与安全

我们把你的隐私放在第一位，用最朴素的语言告诉你我们是怎么做的：

| 你的关心 | 我们如何回应 |
| --- | --- |
| 我的日记安全吗？ | 敏感字段在端侧与传输中均加密保存，并记录每一次访问痕迹（审计）。 |
| 我的数据会被"上交"吗？ | 只有你主动提交的数据才会同步到合作机构；手环、摄像头相关数据**不读取**。 |
| 会不会在后台偷偷录音？ | **不会**。首版不启用后台录音；麦克风是可选模块，**默认关闭**，只有你显式授权才会开启。 |
| 撤销同意会怎样？ | 你可以随时撤回同意，撤回后相关功能会停止。 |
| 有谁在看我？ | 完整的人工接管需由机构专业人员进行确认与跟进，每一步都有记录。 |

## 五、常见问题（FAQ）

**Q1：ECHO Mind 能诊断我有抑郁症吗？**

不能。ECHO Mind 提供记录与筛查提示，任何分数都不是诊断。诊断需要由专业医生完成。

**Q2：我处于紧急危险中，能用它求助吗？**

请优先联系身边可信任的人或当地紧急服务（110 / 120）。ECHO Mind 是日常支持工具，不是紧急响应服务。

**Q3：我的状态会暴露给机构所有人吗？**

只有负责支持你的专业人员能看到你的相关记录，且每一步操作都有审计记录。

**Q4：我拒绝麦克风授权，还能正常使用吗？**

可以。麦克风是可选项，拒绝它不影响核心功能的使用，你可以放心选择。

**Q5：筛查分数高，是不是很严重？**

不一定。分数只是提示，不代表诊断。如果你感到担心，请把它作为和专业人员交流的起点，而不是结论。

**Q6：我的数据会保留多久？**

由于涉及数据留存与删除，请以合作机构提供的隐私政策为准，你也可以随时通过 App 内的数据权利入口提出删除请求。

## 六、技术安装与运行

> 以下内容面向开发者与机构部署人员。普通终端用户无需操作这些步骤。

### 快速验证服务端

```bash
./scripts/release_preflight.sh
```

### 启动后端（本地体验）

```bash
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'
cp .env.example .env
python scripts/seed_demo.py
python scripts/create_demo_tokens.py
uvicorn app.main:app --reload --port 8000
```

启动后可以访问：

- API 文档：`http://127.0.0.1:8000/docs`
- 机构工作台：`http://127.0.0.1:8000/console`
- 健康检查：`http://127.0.0.1:8000/health`
- 就绪检查：`http://127.0.0.1:8000/ready`

### 构建 Android 客户端

```bash
cd android
./gradlew test assembleDebug lint
```

Android 构建基线：AGP 8.13.2、Gradle 8.13、Kotlin 2.3.20、KSP 2.3.9、compile/target SDK 36。自带的 `gradlew` 下载后会校验 Gradle 发行包 SHA-256。

模拟器默认 API：`http://10.0.2.2:8000`。真机和试点环境必须改用机构 HTTPS 网关，不得发布明文 HTTP 配置。

### 生产预检

```bash
cd backend
ENVIRONMENT=pilot \
JWT_SECRET='<至少32字符并由密钥系统注入>' \
FIELD_ENCRYPTION_SECRET='<至少32字符并由密钥系统注入>' \
BOOTSTRAP_KEY='<随机高强度值>' \
DATABASE_URL='<机构PostgreSQL连接>' \
python scripts/pilot_preflight.py
```

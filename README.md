# ECHO Mind

> 每天用一句话，帮你看见「今天的自己」。

**ECHO Mind** 是一款面向成年人的心理健康记录与支持工具，**本地优先、零门槛**：安装即用，画像由手机本机数据生成，数据默认只保存在你的设备里。它不打扰你、不评判你，只是安静地陪你，帮你看清自己日常的节奏。

- 版本：**v0.7.0 工程包**（试点候选版，尚未正式上线）

---

## 一、它是什么？

生活中总有些变化，是回过头来才能看清的：最近睡得晚了、白天活动变少了、手机屏幕亮得比平时久…… 这些细小的变化，我们常常自己都说不清楚。

ECHO Mind 想做的，就是帮你**看见自己**。它像一位安静、耐心的伙伴，用最简单、最不打扰的方式，先「读懂」你平常的生活节奏，然后**每天用一句话告诉你：今天的你，和通常的你有什么不同？**

它只观察行为事实（作息、移动、屏幕互动），**从不猜测你的情绪，也不做任何诊断**。它说的每句话，都来自你自己过去一段时间的真实节奏，而不是拿你和别人比。

> 一句话概括：**ECHO Mind 安静地了解你的日常节奏，每天告诉你——今天的你，和通常的你有什么不同。**

## 二、核心功能亮点

### 🌅 每天看见「今天的自己」

授权后，App 会慢慢熟悉你自己的日常基线。每天打开「今天」页，它会用一句话回答你，比如：

- 「今天开始活跃的时间比你最近的习惯稍晚」
- 「白天整体移动也少了一些」
- 「整体来看，今天和通常的你非常接近」

数据不足时，它会诚实地告诉你「还看不出来」，而不是硬编一个结论。

### 📈 回顾自己的节奏变化

「趋势」页展示最近 **7 天 / 28 天**的画像时间线——哪些节奏最稳定、哪些最近变化比较明显。你可以清楚地看到自己一路走来的变化，而不是只盯着某一天。

### 🤝 需要时，找到能帮你的人（订阅功能）

订阅用户想和专业人士聊聊时，可一键提交支持请求。应用会如实告诉你请求的进度（已送达 / 人工已确认 / 正在接管），**人工支持与日常画像完全独立**，不会因为你的行为数据而自动触发。

### 🧭 由专业团队审签的能力练习（订阅功能）

「能力」页提供由专业团队审签后下发的引导式练习（比如缓慢呼吸）。你可以主动浏览、随时开始，它不做情绪评判，也不因画像数据自动推荐。

### 🛰️ 本地优先，没有账号门槛

无需注册、无需激活码，安装即用：画像由手机本机数据生成，数据默认只保存在你的设备里、不上传。需要云端同步与专业支持时，在「支持」页订阅（可选）后开启。

### 📬 每周小结

每周用一句话回顾你的节律：哪个方面最接近平常、哪个方面变化较明显。本地模式在本机生成同款小结；订阅后由云端分析生成，并通过通知提醒你查看。

### 🔐 你的数据，你做主

随时查看、导出，或要求删除自己的数据。依法需要保留的记录（如审计、危机处置）会明确说明保留原因。

## 三、隐私与安全

我们用最朴素的话说明隐私是怎么做的：

| 你的担心 | 我们如何回应 |
| --- | --- |
| 我的敏感信息安全吗？ | 敏感内容在手机端和传输中全程加密，每一次访问都有记录可查。 |
| 我的原始传感数据会上交吗？ | **不会。** 原始数据只在手机内存里临时处理，不保存、不上云；上传的只是统计摘要。 |
| 它会在后台偷偷录音吗？ | **不会。** 麦克风是可选模块，默认关闭，只有你明确授权才会开启，且原始音频处理完立即丢弃。 |
| 我反悔了怎么办？ | 你可以随时撤回授权。撤回后采集立刻停止、本地缓冲清空，并保留撤回记录。 |
| 谁能看到我？ | 只有负责支持你的专业人员能查看相关记录，且每一步都有审计。 |

## 四、快速上手

1. **获取 App** —— 安装即用，无需注册和激活码（本地模式，数据只在本机）；
2. **首次打开** —— 完成年龄确认，阅读并同意知情说明；
3. **完成引导** —— 按提示授权「被动感知」（几分钟即可完成）；
4. **开始使用** —— 授权后的前几天，App 先学习你的节奏（这期间它会告诉你「正在了解你」）；
5. **每天看一眼** —— 从第 8 天左右起，「今天」页开始给出「今天 vs 平常」的画像；
6. **需要时求助** —— 需要专业人员支持时，在「支持」页订阅（可选），随后一键提交支持请求。

> 小提示：你不用「喂」它任何东西。授权后它就在后台安静地学习你的节奏，你只需要偶尔打开看一眼。

## 五、常见使用场景

**场景一：想更了解自己的作息**

你总觉得最近状态不太对，又说不上来。打开 App，发现「今天开始活跃的时间比平时晚了近一小时」。原来不是错觉——你可以拿这个事实去调整作息，或者和支持人员聊聊。

**场景二：回顾一段时间的起伏**

这段时间压力大，你担心自己是不是「不对劲」。翻看 7 天 / 28 天时间线，发现节奏其实一直很稳定，只有一两天有波动。这个客观的回顾，比胡思乱想更有底气。

**场景三：想把感受说给专业的人听（订阅用户）**

有些话想找人聊聊，又不知道怎么开口。一键提交支持请求，专业支持团队会来联系你。你可以把 App 里的画像当作交流的起点——「你看，我最近确实睡得晚了」。

**场景四：日常的小练习（订阅用户）**

订阅后你会收到几张「能力练习」卡片。午休时花几分钟做一次缓慢呼吸，做完即走，没有负担。

## 六、常见问题（FAQ）

**Q1：ECHO Mind 能诊断我有没有抑郁吗？**

不能。它只做记录和趋势提示，任何趋势或提示都不是诊断。真正的诊断需要由专业医生完成。

**Q2：我正处于危险中，能用它紧急求助吗？**

请优先联系身边可信任的人，或拨打当地紧急电话（110 / 120）。ECHO Mind 是日常支持工具，**不是紧急响应服务**。

**Q3：我的状态会暴露给运营方所有人吗？**

不会。只有负责支持你的专业人员能查看相关记录，每一步操作都有记录。

**Q4：我拒绝麦克风授权，还能正常用吗？**

完全可以。麦克风是可选功能，拒绝它不影响任何核心功能。

**Q5：趋势显示我最近活动变少，是不是很严重？**

不一定。行为趋势只是客观线索，不代表好坏。如果感到担心，请把它当作和专业人员交流的起点，而不是结论。

**Q6：我的数据会保留多久？**

请以服务隐私政策为准。你也可以随时通过 App 内的数据权利入口提出删除请求。

**Q7：它需要我每天打卡、填问卷吗？**

不需要。ECHO Mind 的核心是「被动感知」——你授权后它自动学习你的节奏。旧版的主动记录功能（签到、日记等）已停用，仅保留历史数据的只读查看。

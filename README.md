# ECHO Mind

> 我的手机，开始懂我了。

**ECHO Mind** 是生活在手机里的**个人 AI 伴侣**：它通过持续、克制、可信的感知理解你的生活节律，并通过动态生命场、锁屏与充电屏保、时间记忆与解释，让你随时感受到——**ECHO 在这里，而且它越来越懂你**。

- 版本：**v0.9.0 工程包**（Personal Ambient Intelligence · 三世界架构，尚未正式上线）

---

## 一、它是什么？

ECHO 不再是一个「打开才用的记录工具」，而是一个**长期驻留在手机里的 Personal Ambient Intelligence**：

- **安静存在**：不打扰、不评判、不需要你「喂养」它；
- **理解节律**：授权后持续学习你自己的一天（作息、移动、屏幕节律），形成个人基线——只和你自己的「通常」比较（Me vs Me）；
- **有身体**：ECHO 生命场是它的视觉身体——应用内画报、动态壁纸（主屏/锁屏）、充电屏保共享同一个 ECHO 状态；状态分钟级变化、视觉帧级流动，你渐渐能「看见」今天和平时有什么不同；
- **有记忆**：它记住你确认过的事、你纠正过它的话、你告诉它的特殊时期（出差、备考…）；你可以随时查看、确认、编辑、忘记；
- **能解释**：它说的每一句都能回答「为什么这么说？」——事实与依据分层展示，不确定就明说；
- **可交流**：「问 ECHO」用你的时间上下文回答（最近是不是越来越晚？为什么今天 ECHO 看起来不一样？），不是通用聊天框；每条回答附「依据」（参考了什么/没有使用什么）并支持反馈纠错；
- **可行动**：基础行动（1 分钟呼吸、短暂离开屏幕、什么也不做）免费且由 ECHO 自己执行，不在付费墙后；
- **模型不是 ECHO**：你可以连接自己的 AI（OpenAI 兼容服务/自建网关/局域网端点，BYOM），API Key 仅加密保存在本机；「测试连接」四步验证（认证/模型/结构化输出/基础请求）；换模型，ECHO 不失忆、不换人格。

它**从不猜测情绪、不做诊断**，只做行为观察（Observation，不做 Psychological Interpretation）。产品契约见 `PORTRAIT_CONTRACT.md`。

## 二、核心体验

三个世界：**ECHO（现在）· Journey（我的时间）· Me（我的控制权）**。

### 🌌 ECHO Scene（今天）

打开就是 ECHO 自己：全屏生命场（呼吸渐变 + 粒子 + 波纹），今天的一句话，「为什么这么说？」的事实对照，以及「想做点什么？」。Day 0 就有「初见」画报，第 7 天基线成型时有一次克制的仪式——「我开始认识通常的你了」。

### 🖼️ ECHO Presence（壁纸 / 屏保）

让 ECHO 留在手机上：动态壁纸只渲染视觉、不含文字（锁屏隐私由构造保证），不可见即停止渲染（零额外耗电）；充电放在桌面时进入 Dream 屏保（时间 + ECHO）。**这不是导出壁纸，是持续运行的 ECHO。**

### 🗺️ Journey（旅程 · 我的时间）

每天都是视觉记忆河流中的一个单元：按**天/周/月/季/年**五个尺度回看自己的 ECHO 如何变化（确定性视觉快照，不 AI 生图）；长期变化有叙事与依据，图表只是证据层。

### 🧠 连接你的 AI（可选）

ECHO 无 AI 也完整（感知、画像、Presence、旅程全部本地运行）。连接 AI 后：今日一句话由 AI 基于证据生成（过词表门禁，失败自动回退确定性叙事），「问 ECHO」可以回答关于你的时间的问题。**No AI Provider ≠ App unavailable。**

### 🔐 你的数据，你做主

本地优先、零门槛：原始数据不落盘不上传；EchoPresenceState / 记忆 / AI 推理全部端侧。随时查看、编辑、忘记记忆；导出或删除数据；撤回同意。

## 三、隐私与安全

| 你的担心 | 我们如何回应 |
| --- | --- |
| 我的敏感信息安全吗？ | 敏感内容在手机端与传输中全程加密，每一次访问都有记录可查。 |
| 我的原始传感数据会上交吗？ | **不会。** 原始数据只在手机内存里临时处理，不保存、不上云；上传的只是统计摘要。 |
| 它会在后台偷偷录音吗？ | **不会。** 麦克风是可选模块，默认关闭，只有你明确授权才会开启，且原始音频处理完立即丢弃。 |
| AI 会看到什么？ | 只有为回答当前问题而选择的、已脱敏的节律证据；原始通知内容、原始音频、麦克风特征永不进入任何 AI 任务。 |
| 我的 API Key 安全吗？ | 用 Android Keystore 派生的密钥加密保存在本机独立文件；不上传、不进备份、不出现在任何日志与错误提示里。 |
| 我反悔了怎么办？ | 你可以随时撤回授权。撤回后采集立刻停止、本地缓冲清空，并保留撤回记录。 |

## 四、快速上手

1. **安装即用** —— 无需注册和激活码（本地模式，数据只在本机）；
2. **认识 ECHO** —— 年龄确认 + 隐私承诺（原始数据不离开设备 / 可随时暂停 / 不会因一个行为定义你的心理状态）；
3. **让 ECHO 开始了解我** —— 核心感知授权后，ECHO 苏醒：「ECHO 已开始了解你」，自动进入主页，没有「完成/进入应用」；
4. **第一天就有画报** —— 「初见」+ 已观察 N 分钟；第 7 天基线成型，开始「今天 vs 平常」；
5. **（可选）连接你的 AI** —— Me → AI Intelligence → 填写 Base URL / 模型 / API Key → 验证并连接；
6. **让 ECHO 留在手机上** —— Me → ECHO Presence → 选择 ECHO 壁纸 / 系统屏保设置。

> 小提示：你不用「喂」它任何东西。你可以一周不打开它——壁纸和屏保仍会安静地反映最近的状态。

## 五、常见问题（FAQ）

**Q1：ECHO Mind 能诊断我有没有抑郁吗？**

不能。它只做行为观察与相对比较，任何描述都不是诊断；它不推断情绪、不识别疾病。真正的诊断需要由专业医生完成。

**Q2：我正处于危险中，能用它紧急求助吗？**

请优先联系身边可信任的人，或拨打当地紧急电话（110 / 120）。ECHO Mind 是日常陪伴工具，**不是紧急响应服务**；危机入口在 App 内常驻。

**Q3：我的状态会暴露给运营方所有人吗？**

本地模式数据只在你手机里。订阅后，只有负责支持你的专业人员能查看相关记录，每一步操作都有记录。

**Q4：我拒绝麦克风授权，还能正常用吗？**

完全可以。麦克风是可选模块，拒绝它不影响任何核心功能。

**Q5：「问 ECHO」的回答可信吗？**

回答会标明依据（参考了哪些节律数据、没有使用哪些数据）；证据不足时会明说不足。AI 输出经过词表门禁，越界输出不会展示，自动回退到确定性叙事。

**Q6：ECHO 的记忆会一直留着吗？**

记忆有生命周期（7 天/30 天/365 天，你固定过的永续）；你可以在 Me → What ECHO Knows 里随时确认、编辑、忘记任何一条。

**Q7：它需要我每天打卡、填问卷吗？**

不需要。ECHO 的核心是「被动感知」——你授权后它自动学习你的节奏。旧版的主动记录功能（签到、日记等）已停用，仅保留历史数据的只读查看。

**Q8：订阅包含什么？到期后怎么办？**

免费本地版包含感知、画像、ECHO Scene、Presence（壁纸/屏保）、Journey、基础行动、记忆与 AI 连接的全部功能（数据不出手机）。订阅增加云端同步备份、长周期分析消息与专业支持。到期后本地功能不受影响，云端能力暂停；输入新的订阅激活码即可续订。

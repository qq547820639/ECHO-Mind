# 监控告警与运维值守手册

## P0 告警

- 红色风险事件未送达或队列积压接近 SLA
- 危机入口崩溃或打不开
- 跨租户访问、异常批量导出或权限提升
- 审计哈希链校验失败
- 生产密钥失效、数据库不可用或数据疑似泄漏

动作：立即通知值班人员、机构负责人、安全负责人和工程负责人；暂停受影响功能，保留证据，启动事件响应。

## P1 告警

- API 错误率或延迟持续超阈值
- Outbox 大量积压
- 登录或 MFA 异常
- 备份失败
- 安全规则/内容包版本不一致

## 核心指标

| 类别 | 指标 |
|---|---|
| 安全 | 红色事件创建、未送达、ACK、接管、关闭和复盘 |
| 应用 | 启动、崩溃、ANR、危机入口可用、同步成功 |
| 服务 | API 可用率、P95、数据库连接、队列积压 |
| 隐私 | 导出、越权、权限变更、撤权后读取 |
| 质量 | 告警率、人工确认率、误报、漏转和复核工时 |

## 值守交接

每班记录：未关闭红色事件、SLA 风险、系统故障、待随访、权限异常、版本变化和下一班责任人。不得仅依赖即时消息口头交接。

## 恢复验证

故障恢复后必须确认：事件无丢失、重复事件已去重、审计链有效、用户端送达状态准确、值班队列清空、数据主体请求未遗漏。

# 数据保留、删除和服务退出计划

> 期限为设计建议，最终由实际法律依据、机构规则和合同批准。

## 建议配置

| 数据 | 建议默认 | 删除/退出动作 |
|---|---|---|
| 本地原始语音/视频 | 不保存 | 临时缓存即时清理 |
| 日常签到和日记 | 30/90/180 天可配置 | 用户请求后删除或匿名化，保留处理证明 |
| 量表和练习 | 服务期最短必要 | 同上；与专业记录分离 |
| 风险和人工处置 | 按机构责任规则 | 审批后处理，不允许前端直接擦除 |
| 审计事件 | 长于普通业务数据 | 不保存正文，只保存事件证明 |
| 备份 | 与主数据期限一致并设到期清除 | 删除请求进入备份过期队列 |
| 研究数据 | 独立方案和同意 | 按撤回说明停止后续使用 |

## 用户退出流程

1. 提交停止服务/撤回同意。
2. 立即停止新的心理数据处理和后台同步。
3. 展示未关闭人工事件和紧急支持说明。
4. 生成数据导出/删除选项。
5. 机构确认法定或合同保留例外。
6. 完成删除、匿名化或限制处理，并提供结果摘要。
7. 撤销令牌、设备绑定和工作台访问。
8. 在审计中保留最小处理证明。

## 项目整体退出

试点终止时提前通知用户和机构，停止招募，导出机构所需记录，关闭外部处理者，撤销密钥和账号，验证备份处置，保留不良事件和审计证据，并提供人工服务迁移指引。
